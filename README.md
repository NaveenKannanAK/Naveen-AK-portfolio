# Naveen AK Portfolio — local starter

## Run in VS Code
1. Extract the ZIP.
2. In VS Code, choose **File → Open Folder** and select `ak_data_portfolio`.
3. Open `index.html`. Recommended: install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.
4. You can also double-click `index.html` to open it in your browser.

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
- Replace the LinkedIn link with your public profile URL.
- Replace the EV analytics GitHub profile link with the exact repository URL once available.
- Verify all skills, education, dates, and project descriptions.

Files: `index.html` (content), `style.css` (design), `script.js` (mobile navigation and copy-email behavior).

Next step after local review: publish with GitHub Pages.
